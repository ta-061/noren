# Noren 0.1.0-preview — release notes

> **Read this first.** This is an explicitly dated developer
> preview, not a finished terminal. Decision [D-M8-001](../../coordination/decisions/D-M8-001-preview-scope.md)
> scoped it honestly: a bitmap font with bounded coverage (no CJK
> or emoji glyphs), no IME input, no accessibility surface, macOS
> (Apple Silicon) only, a workspace sidebar that is a first vertical
> slice rather than the full product, and fixed built-in themes. What
> does not work is enumerated clause by clause in [known limitations](../../known-limitations.md),
> and that page outranks anything below: features listed here are the
> merged history, stated with their limits, not a product claim.
