# Noren v0.1 requirements

- Status: Accepted product requirements; implementation approval is limited to
  the first macOS local-PTY PoC below
- Decision date: 2026-08-03
- Related Issue: [#6](https://github.com/ta-061/noren/issues/6)

Noren v0.1 is a Preview, not a compatibility claim. Requirements marked **PoC**
are the only work authorized by this design gate. Requirements marked **Later**
remain v0.1 outcomes but need their own Issue and design/security review before
implementation.

## Functional requirements

| ID | Gate | Requirement | Passing evidence |
| --- | --- | --- | --- |
| FR-001 | PoC | The repository provides a Rust workspace with pinned toolchain and CI. | A clean checkout builds and tests all workspace crates on the recorded macOS runner with the pinned toolchain. |
| FR-002 | PoC | Noren opens one resizable macOS window on the application main thread. | A macOS smoke test records create, redraw, resize, close, and clean event-loop exit. |
| FR-003 | PoC | Noren directly starts local `/bin/zsh` attached to a new PTY, without constructing a shell command string, using the validated absolute `$HOME` as cwd and the documented environment policy. | An integration test observes a controlling terminal, expected argv/cwd/environment, and a live child; security review finds no `-c` concatenation or ambient-cwd fallback. |
| FR-004 | PoC | Pressed printable-text, Enter, Backspace, Tab, Escape, arrow, and Ctrl-key events are converted to the specified terminal bytes and sent to the PTY; release or unsupported modifier events send nothing. | Table-driven adapter tests assert exact bytes and repeat behavior; unsupported Cmd/Option/IME/dead-key cases return a payload-free typed drop event and are never degraded to a base character. |
| FR-005 | PoC | PTY bytes update terminal state and the resulting visible cells are drawn in the window. | A deterministic helper emits prompt, ASCII, UTF-8, control, and scrolling fixtures; state snapshots and a macOS rendered-frame capture match their oracles. |
| FR-006 | PoC | Each final non-zero window size is converted to stable rows/columns and propagated to terminal state, renderer, and PTY. | Unit traces cover duplicates/zero size; a real PTY helper reads the final kernel window size after resize storms. |
| FR-007 | PoC | EOF, child exit, window close, and component error enter an observable terminal state and perform idempotent, deadline-bounded shutdown. | Normal-path tests show the child is reaped and both workers join; a held slave/blocked reader reaches a reported forced-exit fallback within 2 s; repeated close never hangs or panics. |
| FR-008 | Later | The terminal foundation adds bounded scrollback, selection, copy/paste, search, configuration, and diagnostics without weakening pass-through. | Feature Issues define state, privacy, performance, and compatibility fixtures before implementation. |
| FR-009 | Later | Noren manages the workspace outside the terminal — a sidebar of external context (projects, git worktrees, SSH connections, agents, and terminal sessions) where sessions are created, selected, and terminated — and shows exactly one selected terminal session. Tabs, pane splits, layout, and in-terminal focus are delegated to Zellij (or the application inside the session), never duplicated by Noren. Configurable shortcuts drive Noren-side actions only and must not collide with Zellij bindings; a non-keyboard recovery surface remains reachable regardless of binding state. | A sidebar-lifecycle and single-session-selection suite passes: sessions are created/selected/terminated from the sidebar, exactly one is visible, no Noren-side tab/pane/split exists, and a collision/keybinding suite asserts Noren shortcuts never steal a chord Zellij binds while all other keys forward unchanged. |
| FR-010 | Later | Remote sessions use verified OpenSSH semantics and never take custody of private keys or passphrases. | The SSH ADR, host-key/config matrix, and security gates pass before code starts. |
| FR-011 | Later | Agent launch/status features report only evidence-backed states and do not embed an LLM chat product. | Adapter contracts, provenance fixtures, and `Unknown` fallbacks pass. |
| FR-012 | Later | Preview presentation includes documented themes, IME/CJK/HiDPI behavior, and keyboard/accessibility access. | Platform-specific visual, contrast, IME, and assistive-technology gates pass. |

## Non-functional requirements

Measurements must record hardware, OS, build profile, fixture, and sample count.
The first implementation may revise a proposed numeric bar only in a reviewed
commit that explains the observed evidence.

| ID | Gate | Requirement and pass bar |
| --- | --- | --- |
| NFR-001 | PoC | **Input integrity:** every supported key fixture produces the exact expected bytes; no supported event is lost, duplicated, or consumed by an app shortcut. |
| NFR-002 | PoC | **Responsiveness:** on the recorded Apple Silicon reference Mac, input-to-visible-frame and final resize-to-frame are each p95 <= 100 ms over at least 100 samples; the stretch target is one 60 Hz frame. |
| NFR-003 | PoC | **Backpressure:** during a 100 MiB output fixture, the maximum main-loop gap is <= 250 ms, peak resident memory is <= 64 MiB above the post-start baseline, configured channel capacities never exceed their documented bounds, and no data queue is unbounded; after drain and 60 s idle, resident memory is <= 16 MiB above baseline. |
| NFR-004 | PoC | **Lifecycle:** normal close and EOF reap the child and join workers within 2 s. If a descendant retains the slave and reader EOF cannot be joined, the app reports `ReaderJoinTimeout`, detaches that reader for process-exit cleanup, and still exits within 2 s; repeated close is safe. |
| NFR-005 | PoC | **Isolation:** each injected PTY, parser, renderer, or channel failure becomes a typed app event; a sentinel lifecycle/redraw event queued afterward is processed within 100 ms, and a subsequent Close completes teardown within 2 s. |
| NFR-006 | PoC | **Security/privacy:** process arguments remain structured; terminal bytes are never authority; logs contain no terminal payload, environment value, secret, or user keystroke. |
| NFR-007 | PoC | **Build quality:** pinned Rust CI runs formatting, Clippy with warnings denied, workspace tests, `python3 scripts/check_docs.py`, `python3 -m unittest scripts/test_check_docs.py`, and dependency metadata capture; each command must exit zero. Every `unsafe` block requires a `SAFETY` comment. |
| NFR-008 | PoC | **Reproducibility:** CI and local handoff record `rustc --version --verbose`, `cargo --version --verbose`, installed targets, macOS version, architecture, lockfile, and exact direct dependencies. |
| NFR-009 | Later | **Portability/accessibility/release:** macOS and Linux backend matrices, assistive technology, signing/notarization, packaging, and release-integrity gates must pass before Preview claims. |

## First implementation cut line

The first implementation Issue may satisfy only FR-001 through FR-007 and
NFR-001 through NFR-008. SSH, agent state, themes, remote daemon, production
IME/accessibility, and broad cross-platform parity are prohibited in that Issue.
Native tabs and pane splits are out of scope for every milestone
([ADR 0003](../adr/0003-noren-zellij-responsibility-boundary.md)): Noren manages
the workspace outside the terminal and delegates in-terminal layout to Zellij. A
passing PoC supplies evidence for later ADRs; it does not convert its candidate
libraries into permanent production choices.
